# Maze Renderer 使用者手冊

第一人稱迷宮瀏覽程式：左邊是上帝視角地圖（Map View，含紅色視錐），右邊是玩家視角（Maze View）。

## 1. 啟動與載入迷宮

1. 執行 `MazeVisibility`。
2. 在 Map View 按 **Load Maze**，輸入迷宮檔完整路徑（例如 `Sources/maze-10x10-50`）。
3. 載入後用滑鼠點一下 **Maze View** 視窗取得鍵盤焦點，再開始操作。

建置方式：`CMakeLists.txt` 已設定好，`include/`、`lib/` 內含 FLTK 與 OpenGL 函式庫，用 Visual Studio 或 CMake 建置 `MazeVisibility` 專案即可。

## 2. 畫面說明

| 畫面 | 說明 |
|---|---|
| Map View | 迷宮俯視圖。彩色線＝牆，紅色扇形＝你的位置＋面向＋視角。青色線＝窗戶，紅色線＝門，開啟中的門也會顯示。 |
| Maze View 上半（淺灰） | 室內天花板。 |
| Maze View 下半（深灰） | 室內地板。 |
| 藍天＋綠地 | **室外**。只有透過外側窗戶或打開的外側門才看得到。記法：灰＝室內，藍綠＝室外。 |
| 青色框牆面 | 窗戶本體（窗框）。 |
| 紅色牆面 | 門（關閉時）。 |

## 3. 操作一覽

操作前請先點一下 Maze View 視窗，否則按鍵不會送到 3D 視窗。

| 按鍵 / 滑鼠 | 動作 |
|---|---|
| `W` / `S` | 前進 / 後退 |
| `A` / `D` | 左平移 / 右平移 |
| `←` / `→` | 左轉 / 右轉 |
| `G` | 把正前方 6 單位內最近的牆變成窗戶；再按一次還原 |
| `E` | 開／關正前方的門；前方沒有門時，把最近的牆變成門並打開 |
| 滑鼠左鍵拖曳 | 左右拖＝轉向，前後拖＝前進後退 |

碰撞說明：牆、關閉的門、窗戶都會擋人。門要等滑開動畫過半（約 0.3 秒）才能走過去；外側門只能看不能走出去。

## 4. 窗戶（加分功能）

- 按 `G`：面對牆按一下，該牆中央出現橫向窗洞，窗框為青色。
- 內側窗戶：可看到隔壁房間的牆面，走近走遠都不會閃爍。
- 外側窗戶：可看到外面的藍天綠地。
- 窗戶永遠擋人（玻璃），只透視不通行。
- 進階：直接編輯迷宮檔，把某條 `opaque=1` 邊的顏色改為 `0 1 1`，該邊即為窗戶。

## 5. 門（加分功能）

- 按 `E`：面對門按一下開／關（約 0.7 秒滑動動畫）；面對普通牆按 `E` 會把該牆變成紅色門並打開。
- 開門後直接用 `W` 走過去即可，地圖上的 view cell 會跟著更新。
- 外側門：打開看得到藍天綠地，但為了不走出迷宮，碰撞仍擋住。
- 進階：直接編輯迷宮檔，把某條邊的顏色改為 `1 0 0`，該邊即為預設關閉的門。

## 6. 常見問題

1. **按鍵沒反應**：先用滑鼠點一下 Maze View 視窗取得焦點。
2. **門開了卻走不過去**：等動畫滑開過半再走；確認面對的是門洞中央。
3. **想還原被 G/E 改過的牆**：窗戶再按一次 `G` 即還原；門一旦生成即為永久門（重載迷宮檔可全部還原）。
4. **視角穿牆**：屬碰撞保護（`BUFFER` 距離），貼牆時會被擋下為正常現象。
